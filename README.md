## Selected AI Projects

### [Multimodal Preprocessing API](https://github.com/Lee-Hyeong-Jin/multimodal_preprocessing_api)

A PDF preprocessing workflow that combines text extraction and vision-language model summarization to prepare document data for downstream applications.

- Splits PDF files into page-level documents and extracts page text and visual metadata.
- Renders document pages and uses an OpenAI vision model (configured with GPT-4o by default) to generate page summaries.
- Publishes page summaries and metadata to a durable RabbitMQ queue for downstream processing.

**Technologies:** Python · FastAPI · OpenAI API · PyMuPDF · pdf2image · Pydantic · RabbitMQ · Docker

### RAG Data Pipeline

RAG data pipeline implementation for a system-integration project.

**Focus:** Document/data preparation · Retrieval-augmented generation workflows

### High School Credit System Course Recommendation Service

A course recommendation service designed around the Korean high school credit system.

**Focus:** Recommendation workflows · Education technology

### [Robotics Curriculum & Learning Platform](https://github.com/Lee-Hyeong-Jin/devjinlab_robotics_curriculum)

An open-source curriculum and learning-assist platform for progressing from robotics fundamentals to advanced and learning-based topics.

- Organizes structured lessons across mathematics and physics, kinematics, mobile robot control, sensors and perception, state estimation and SLAM, navigation, manipulation, ROS 2, and learning-based robotics.
- Includes a CLI for lesson progression, study-time tracking, quizzes, spaced-repetition reviews, and progress reports.
- Provides an offline study site and a self-hosted server mode with an API and web frontend.

**Technologies:** Python · FastAPI · Pydantic · SQLite · PostgreSQL · Next.js · Docker
